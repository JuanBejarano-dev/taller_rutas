# Flutter sencillo: pantallas de autenticación

Todo el código de las seis pantallas está en `lib/main.dart`.

## Pantallas
1. Iniciar sesión
2. Registro
3. Recuperar contraseña
4. Código de verificación
5. Nueva contraseña
6. Inicio

Es una maqueta de práctica: no usa base de datos ni servidor.

## Ejecutar
1. Descomprime el ZIP.
2. Abre la carpeta del proyecto en Android Studio o VS Code.
3. Ejecuta `flutter pub get`.
4. Ejecuta `flutter run`.

## Datos de prueba
- Login: correo que contenga `@` y cualquier contraseña.
- Registro: completa los campos, correo con `@` y contraseña de mínimo 4 caracteres.
- Código de verificación: `1234`.
- Nueva contraseña: ambas deben coincidir y tener mínimo 4 caracteres.
